# HDC imagery pack implementation map

**Source package:** `hdc-imagery-package(2).zip` (received 2026-10-10)

## Handling rule

The 11 PNG files are reference-only generated concepts. Keep them out of the public asset directory and do not present their products, copy, process claims, or compositions as verified HDC production evidence. Use them to guide hierarchy, crop, rhythm, and interaction. Continue using replaceable image slots with approved HDC assets and truthful alt text.
