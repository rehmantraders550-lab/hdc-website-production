## Production rules

- Media is evidence, not decoration.
- Never imply a depicted machine is for sale.
- AI-generated visuals must not be presented as verified HDC client projects.
- No invented logos, client attribution, production specifications, durability values, capacity, or certifications.
- Keep UV DTF surface compatibility qualified where validation is required.
- Prefer real HDC project photography over generated imagery when verified real work is available.
- Use dedicated mobile crops / posters for major media where the desktop crop loses the print evidence.

## Recommended repository destinations

- Images: `assets/images/approved/`
- Videos: `assets/videos/approved/`
- Future verified client work: `assets/images/projects/`
- Brand identity: `assets/brand/`

## Phase 5 visual priority mapping

Tier 1 use should prioritize hero media, technology media, surface examples, print specimens, and verified selected-work evidence. Remaining assets can support applications, process, quality, and large-format sections only where their content actually proves the section's claim.
